# 11 — Arquivos: FilePicker

`src/10-io.kf`

## FilePicker

```kof
FilePicker(String label): FilePickerParts    // .root()
FilePickerState.loadedPath                    // último caminho carregado
filePreview(content): String                  // pura: 5 linhas + rodapé
```

Input de caminho + botão `carregar ⤓` + preview. A leitura usa kof.io
(`Path(p).exists()` / `.readText()`) e o resultado passa por
`filePreview`: primeiras 5 linhas com prefixo `│`, rodapé `+N linhas`,
`(arquivo vazio)` para conteúdo vazio, erros no próprio preview.

```kof
var picker = FilePicker("abrir log")
w.bind(picker.root())
// após carregar:
abrirCom(FilePickerState.loadedPath)
```

## Receita: seletor + salvamento

kof.io também escreve (`writeText`). Combine com Dialog para confirmar:

```kof
Int salvarBtn = Button("salvar cópia", () -> {
    if (!isBlank(FilePickerState.loadedPath)) {
        Path(FilePickerState.loadedPath).writeText(conteudoAtual)
        Toast("cópia salva")
    }
})
```
